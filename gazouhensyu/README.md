# ぬりえ工房 v3 — AI背景削除つき・写真忠実版

GitHub Pagesで公開できる、写真を白背景・黒線のぬりえにする無料のWebアプリです。
**v3ではAI補正に「背景を全部消す」モードを追加しました。**

## 新しいAIモード

1. 「写真を選ぶ」→「AI補正を使う」をONにします。
2. 「AI補正の種類」から以下を選びます。
   - **背景を全部消す（人物・動物・モノ）**：汎用的な背景除去。初回ダウンロード約44MB。モデルは `onnx-community/ormbg-ONNX`、量子化モデル。
   - **背景を全部消す（人物専用・軽量）**：人物写真の切り抜き専用。初回ダウンロード約7MB。`Xenova/modnet`。
   - **従来の輪郭補助（背景は残す）**：従来の領域分類AIによる輪郭補助。
3. 「ぬりえをつくる」を押すと、AIが被写体のマスクを推定 → 背景の輪郭を削除 → 被写体の輪郭を抽出 → 白背景・黒線の画像を作成します。
4. 「PNGを保存」で保存します。

### 大事な注意

- **完全な背景除去は保証できません。** 被写体と背景が重なる部分、髪の毛、細い隙間、複数の被写体などはAIが誤判定することがあります。線画はAIが残した領域を元に生成します。
- モデルを初めて使うときはインターネットが必要です。モデルのダウンロードと推論は端末の性能によっては重くなります。
- 重いときは「人物専用・軽量」（人物写真に限る）や、画質設定の「軽量・高速」を使用してください。
- 背景除去に失敗したらエラーを表示し、背景が残った画像を成功として表示しません。従来の輪郭補助のみ、失敗したら通常変換へ戻る仕様です。
- 進捗バーは判明している処理段階を表示します。**AIモデルの推論時間の正確な％は取得できない**ため、「処理中」の表示と、最後にWorkerから応答が来た時刻を併用します。
- 写真はブラウザ内で処理され、AIモデルの推論のためにサーバーへ送信しません。JavaScript・WASM・AIモデルのダウンロード通信は行われます。
- 基本変換はブラウザ内の画像処理アルゴリズム。AI補正を使う場合にのみ機械学習モデルをダウンロードします。
- 画面を `file:///` で直接開くとWeb Workerのセキュリティ制限で失敗します。GitHub PagesまたはローカルHTTPサーバーで開いてください。

## GitHubへの更新（現在のリポジトリ: akatuki04/nurie_studio2）

1. ZIPをダウンロードして「すべて展開」します。
2. [リポジトリのアップロード画面](https://github.com/akatuki04/nurie_studio2/upload/main)を開きます。
3. 展開した**フォルダの中身**を選び、リポジトリの**最上位**にアップロードします。最低限 `index.html`, `style.css`, `app.js`, `outline-worker.js`, `ai-worker.js` が必要です。ホーム画面への追加用に `sw.js`, `manifest.webmanifest`, `icons` も含めます。
4. 上書きの確認が出たら、既存ファイルの更新を選びます。右下の「変更をコミットする」を押してください。
5. Pagesが `main` / `/(root)` なら設定変更は不要です。公開URL: https://akatuki04.github.io/nurie_studio2/
6. 以前の画面が表示されたら、ブラウザを再読み込みしてください。ホーム画面に追加した場合は再起動が必要なこともあります。

> 以前の `index.html` だけを更新しても動きません。**必ず `app.js`, `style.css`, `ai-worker.js`, `outline-worker.js`, `sw.js` も一緒に更新**してください。

## Windowsで試す

Pythonがある場合は `起動する.bat` を実行します。手動ならこのフォルダで `python -m http.server 8000` を実行し `http://localhost:8000` を開きます。ローカルでもAIモデル取得にはインターネットが必要です。

## 動作確認済みの範囲

- JavaScriptファイルの構文チェック
- DOMの表示とAIモード切り替え（ヘッドレスChromium）
- 背景マスクを使用した線画生成エンジンの単体テスト（**模擬マスクで背景領域の黒線がゼロ**）
- **ブラウザでの実際のAIモデルダウンロード・推論／スマホ実機は未検証**です。公開後に写真で確認してください。

## 主要ファイル

- `index.html`：画面・新しいAIモード選択
- `style.css`：スマホを含むデザイン
- `app.js`：画像の読み込み・進捗・ダウンロード・AIモード切替
- `outline-worker.js`：写真に忠実な線画変換。AIの背景マスクで背景を除外
- `ai-worker.js`：背景削除AI／従来の輪郭補助AI
- `sw.js`, `manifest.webmanifest`, `icons/`：PWA対応
